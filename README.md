# INGEVERA · Ingeniería y Soluciones Eléctricas

Sitio web estático (HTML, CSS y JS sin compilación) para INGEVERA, Casablanca, Región de Valparaíso.

## Publicar en Cloudflare Pages

1. Cloudflare → Workers & Pages → Create → Pages → Connect to Git → elegir `ingevera`.
2. Framework preset: **None**. Build command: *(vacío)*. Build output directory: `/`.
3. Save and Deploy. Cada `git push` a `main` vuelve a publicar.
